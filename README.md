# i9Core — instaladores do aplicativo

Este repositório guarda só os instaladores (APK) do app i9Core e o arquivo `versao.json`, que o app consulta para avisar quando há versão nova.
O código do aplicativo fica em outro repositório, privado.

| Unidade | Instalador |
|---|---|
| Cabedelo | `apk/i9core-cabedelo.apk` |
| Fortaleza | `apk/i9core-fortaleza.apk` |
| Matriz | `apk/i9core-matriz.apk` |
